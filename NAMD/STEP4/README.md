# STEP4: Nonadiabatic Molecular Dynamics (NAMD)

This step performs Nonadiabatic Molecular Dynamics (NAMD) simulations using the vibronic Hamiltonians and non-adiabatic couplings generated in STEP3. It then analyzes the resulting excited-state relaxation dynamics.

The simulations are carried out with four different surface-hopping methods: FSSH, FSSH2, IDA, and MSDM.

## Simulation Workflow

### 1. Main Driver: NAMD_MB.py

The `NAMD_MB.py` script runs the NAMD simulation for a given method, structure, and initial condition. It reads the vibronic Hamiltonians and non-adiabatic couplings generated in STEP3 and propagates the trajectories using one of the four surface-hopping algorithms.

### 2. Surface Hopping Recipes (recipes/)

Four different surface-hopping methods are implemented:

| Recipe | Method | Key Feature |
|--------|--------|-------------|
| fssh_nbra.py | FSSH | Standard Tully FSSH |
| fssh2_nbra.py | FSSH2 | Alternative FSSH with robust switching |
| ida_nbra.py | IDA | Instantaneous Decoherence at Attempted hops |
| msdm_nbra.py | MSDM | Simplified Decay of Mixing |

Each recipe defines:
- The hopping probability calculation.
- The decoherence correction (if applicable).
- The acceptance / rejection rules for proposed hops.

### 3. Simulation Outputs (Generated Locally)

For each structure, method, and initial condition, the simulation produces a folder containing:

- `_dyn_params.txt` — Dynamics parameters.
- `_model_params.txt` — Model parameters.
- `mem_data.hdf` — The HDF5 file containing the populations and other data.

**Important:** These output folders are **not** included in this repository, because they are large and can be regenerated by running `NAMD_MB.py`. They are created locally in the user's working directory.

The main HDF5 content is:

| Data field | Description |
|------------|-------------|
| time/data | Time array in atomic units |
| sh_pop_adi/data | Adiabatic state populations for each trajectory |

## Data Analysis

### Main Analysis Notebook: plotting.ipynb

This notebook performs the complete data analysis workflow:

1. Reads all HDF5 files from the simulation directories.
2. Extracts the S0 population from `sh_pop_adi/data[:, 0]` for each batch.
3. Fits each batch to a stretched exponential model:

   P_S0(t) = 1 - exp[-(t/tau)^beta]

4. Applies R2 thresholds to filter out poorly fitted batches.
5. Builds an ensemble from accepted batches and fits the ensemble-averaged curve.
6. Performs bootstrap analysis (1000 resamples) to estimate confidence intervals.
7. Calculates the Photoluminescence Quantum Yield (PLQY) using:

   Phi = tau_nr / (tau_nr + tau_r)

8. Saves all results to a locally generated folder named `analysis_results_batch_average/` for subsequent plotting.

**Important:** The first cell of this notebook does not generate figures. It only processes data and saves results. The subsequent cells generate the figures.

### Entropy Analysis Notebook: step4_entropy.ipynb

Analyzes the Shannon entropy of the electronic wavefunction to characterize the degree of quantum-state diffusion.

## Analysis Outputs (Generated Locally)

Running the first cell of `plotting.ipynb` creates a folder named `analysis_results_batch_average/` in the local working directory. This folder is **not** part of the repository (it is generated locally). It contains:

### 1. analysis_results.pkl

Main results dictionary (Python Pickle format).

Contents:

- `all_results`: Nested dictionary with keys `(structure, method)`.
  - `accepted_batches`: List of dictionaries (time, population, tau, beta, R2).
  - `rejected_batches`: Same, but for batches that failed the R2 threshold.
  - `ensemble`: Dictionary with `time_fs`, `mean`, `std`, `matrix`.
  - `final_fit`: Dictionary with `tau_fs`, `tau_ps`, `beta`, `r2`.
  - `bootstrap`: Dictionary with `tau_samples`, `beta_samples`, `tau_ci`, `beta_ci`, `fit_lower`, `fit_upper`.
  - `plqy`: Dictionary with `samples` and `ci`.

- Global metadata: `structures`, `methods`, `r2_thresholds`, `iconds`, `ntraj_per_batch`, `confidence_level`, `max_time_fs`, `n_ensemble_points`, `n_bootstrap`, `bootstrap_seed`.
- Experimental and reference data: `experimental_tau_ps`, `radiative_tau_computed_ns`, `radiative_tau_computed_err_ns`, `radiative_tau_experimental_ns`, `experimental_plqy_percent`, `relative_quantum_yield_3s`.

### 2. batch_curves.csv

Raw S0 population data for every batch (accepted and rejected).

| Column | Description |
|--------|-------------|
| structure | Structure name |
| method | NAMD method (FSSH, FSSH2, IDA, MSDM) |
| icond | Initial condition index |
| status | "accepted" or "rejected" |
| time_fs | Time in femtoseconds |
| s0_population | S0 population |
| tau_ps | Fitted nonradiative lifetime (ps) |
| beta | Fitted stretch exponent |
| r2 | R2 of the fit |

### 3. ensemble_curves.csv

Ensemble-averaged S0 population curves and their fits.

| Column | Description |
|--------|-------------|
| structure | Structure name |
| method | NAMD method |
| time_fs | Time in femtoseconds |
| ensemble_mean | Ensemble-averaged S0 population |
| ensemble_std | Standard deviation across batches |
| fit | Fitted curve (stretched exponential) |
| fit_ci_lower | Lower 95% CI from bootstrap |
| fit_ci_upper | Upper 95% CI from bootstrap |

### 4. comparison_data.csv

Summary table with tau, beta, PLQY, and experimental references.

| Column | Description |
|--------|-------------|
| structure | Structure name |
| method | NAMD method |
| tau_ps | Nonradiative lifetime (ps) |
| tau_ci_low | Lower 95% CI for tau |
| tau_ci_high | Upper 95% CI for tau |
| beta | Stretch exponent |
| beta_ci_low | Lower 95% CI for beta |
| beta_ci_high | Upper 95% CI for beta |

### 5. summary_results.txt

Human-readable summary of the analysis. For each structure-method combination:

- Number of accepted and rejected batches.
- Fitted tau, beta, and R2.
- Bootstrap 95% CIs for tau and beta.
- Calculated PLQY and its 95% CI.

## How to Run

### 1. Run NAMD Simulations

python NAMD_MB.py --method FSSH --structure adamantane --icond 1

Repeat for all methods (FSSH, FSSH2, IDA, MSDM), all structures (adamantane, 1methyl_adamantane, 2methyl_adamantane, 3methyl_adamantane), and all initial conditions (icond = 1, 101, 201, ..., 2901).

### 2. Run the Analysis Notebook

Open `plotting.ipynb` in Jupyter and run the cells sequentially. The first cell performs the full analysis and saves the results to `analysis_results_batch_average/`; the subsequent cells generate the figures.

### 3. Generate Figures

- Nonradiative Lifetime Comparison
- Radiative Quantum Yield Comparison
- Beta Comparison
- 4x4 Grid Plot
